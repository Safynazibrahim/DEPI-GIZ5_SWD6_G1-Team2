# PHPTravels – Software Testing Graduation Project

## About the Project

This repository contains the documentation, test artifacts, and deliverables of our Software Testing Graduation Project as part of the **Digital Egypt Pioneers Initiative (DEPI)**.

The project focuses on testing the **PHPTravels Demo Web Application** to evaluate its functionality, identify defects, and verify its main business workflows across different user roles.

Our goal is to apply software testing principles and practices throughout the project lifecycle, starting with Manual Testing and progressing to Automation Testing.

## Application Under Test

**Application:** PHPTravels Demo  
**Website:** https://phptravels.com/demo  
**Application Type:** Web Application

The application will be explored and tested based on the functionalities and user roles available in the provided demo environment.

## Project Objectives

- Understand the application's business domain and user workflows.
- Verify the functionality of the available application features.
- Design and execute comprehensive test scenarios and test cases.
- Identify, document, and report software defects.
- Validate workflows involving multiple user roles.
- Apply software testing techniques and best practices.
- Build a foundation for the subsequent Automation Testing phase.

## Testing Scope

The project initially focuses on the following four user roles, subject to their availability in the demo environment:

| User Role | Testing Focus |
|---|---|
| Customer | Account management, search, and booking workflows |
| Admin | Dashboard and administrative operations |
| Agent | Available agent functionalities and operations |
| Supplier | Available supplier functionalities and operations |

The final scope will be confirmed after exploring the application and identifying its accessible features.

## Testing Approach

The project will be carried out in two main phases:

### Phase 1: Manual Testing

The initial phase focuses on manually evaluating the application's functionality.

Testing activities include:

- Functional Testing
- Positive and Negative Testing
- Exploratory Testing
- End-to-End Testing
- Boundary Value Analysis
- Equivalence Partitioning
- Error Guessing
- Defect Reporting and Retesting

Test cases will initially be documented in a traditional format using Google Sheets.

### Phase 2: Automation Testing

The next phase will focus on automating selected test scenarios from the manual testing phase.

Planned activities include:

- Identifying suitable test cases for automation.
- Converting selected scenarios into BDD format using Gherkin.
- Designing and implementing an Automation Framework.
- Developing and executing automated test scripts.
- Performing automated regression testing.

*Automation tools, technologies, and framework details will be added once finalized.*

## Project Timeline

The project will be developed through the following stages:

1. **Test Planning:** Define objectives, scope, testing approach, and responsibilities.
2. **Application Exploration:** Explore the available functionalities and user roles.
3. **Test Design:** Identify test scenarios and prepare detailed test cases.
4. **Test Execution:** Execute manual test cases and record results.
5. **Defect Management:** Report, track, and retest identified defects.
6. **Automation Phase:** Select suitable scenarios and implement automated tests.
7. **Final Reporting:** Prepare the final testing documentation and project summary.
